# Nearfield

Локальный web-прототип HRTF-плеера для наушников. Внутри уже подключены `Poker Face` и `Love Me Not` из корня проекта.

## Запуск

```bash
cd "/Users/softfoxxy/Projects/360 sound generation"
python3 -m http.server 4173 --directory dist
```

После этого открыть <http://localhost:4173> и нажать Play. Для честной проверки нужен именно браузерный сервер: при открытии `index.html` напрямую браузеры могут блокировать аудио и гироскоп.

## Что реализовано

- трёхполосное разделение каждого стереоканала;
- шесть независимых HRTF-источников через Web Audio API;
- синтезированная стереокомната с ранними отражениями;
- три размера сцены, глубина и уровень комнаты;
- ручной поворот сцены и head tracking через `DeviceOrientationEvent`;
- модельный EQ-профиль Marshall Major V с запасом по уровню;
- загрузка собственных локальных аудиофайлов без отправки на сервер.

Профиль Major V — модельная настройка по характеристикам модели, а не индивидуальная калибровка конкретного экземпляра. В приложении Marshall рекомендуется использовать ровный EQ, чтобы не получить двойную коррекцию.
