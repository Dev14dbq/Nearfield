# Nearfield

Музыкальный плеер с настоящим 3D-звуком для наушников. Ищет музыку в Яндекс Музыке, SoundCloud и Spotify. Избранное скачивает и раскладывает на вокал, бас, ударные и инструменты, а потом расставляет их вокруг слушателя.

## Установить на Mac

```bash
./app/build-mac.sh
```

Скрипт собирает приложение и кладёт его в «Программы». Потом оно открывается из Launchpad или Spotlight. Библиотека, вход в сервисы и настройки лежат в `~/Library/Application Support/app.nearfield.player` и при обновлении сохраняются.

Для сборки нужны Rust и `tauri-cli` (`cargo install tauri-cli`).

## Что внутри

```
app/
  build-mac.sh          сборка и установка в «Программы»
  src-tauri/            нативная часть (Rust, Tauri 2)
    src/
      lib.rs            запуск приложения и общее состояние
      commands/         команды для интерфейса: поиск, медиатека, плейлисты, аккаунты
      providers/        Яндекс Музыка, SoundCloud, Spotify, LRCLIB
      merge.rs          склейка одного трека с разных площадок
      db.rs             локальная медиатека (SQLite)
      prep.rs           скачивание и разделение на стемы (Demucs) в фоне
      media.rs          «Сейчас играет», медиаклавиши, кнопки наушников
  ui/                   интерфейс (HTML, CSS, JS без сборщика)
    index.html
    css/                tokens, layout, components, pages, player, phone
    js/                 экраны, плеер, Моя волна, настроения, сцены звука
    engine/             звуковой движок: HRTF, комнаты, хореография, анализ бита и стиля
    img/                обложка «Избранного» и 3D-иконки
dev-samples/            локальные тестовые треки, в git не попадают
```

## Разделение на стемы

Для полноценного 3D трек делится на четыре дорожки с помощью Demucs. Приложение ищет его в `.venv` проекта, а если не находит, в «Настройках» есть кнопка установки (~1 ГБ). Разделение идёт в фоне, только пока музыка на паузе.
